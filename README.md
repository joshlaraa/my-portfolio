# Josh Lara's Portfolio

Hey 👋! My name is Josh Lara, a Software Engineering graduate of California State University San Marcos with both industry and project experience.

## Tech Stack

- React 19, TypeScript
- Vite, Tailwind CSS v4
- shadcn/ui, Magic UI, Motion
- React Router
- Vercel (hosting + analytics)

## Getting Started

```bash
npm install
npm run dev        # start the dev server
npm run build      # typecheck + production build
npm run lint       # eslint
npm run typecheck  # tsc only
```

## Project Structure

- `src/data/portfolio.ts` — all site content (projects, experience, skills, links)
- `src/components/` — page sections and shared UI
- `src/pages/` — routes (home, privacy, terms, 404)
- `public/` — static assets (project screenshots are 1600px WebP)
